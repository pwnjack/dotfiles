# Keybindings overlay

`quickshell/keybinds-overlay/shell.qml` is an on-demand, read-only HUD started by
`scripts/hyprland/keybinds-overlay.sh` (lock, IPC toggle, daemonize; exits on
close). `sheet.mjs` is the pure model (filter, highlight, contrast fallback,
column balancing). Behaviour and checks: [keybinds-overlay.md](../keybinds-overlay.md).
