# Scripts directory map

- `hyprland/` — Session and desktop scripts: startup, `respawn.sh` (restarts a crashed session daemon; autostart, `waybar.sh` and the settings panel start Waybar, SwayNC, hypridle, hyprsunset and the polkit agent through it), `lock.sh`, wallpaper switching (`wall.sh`, `restore-wallpaper.sh`), the Quickshell launchers (`settings-panel.sh`, `capture-bar.sh`, `keybinds-overlay.sh`, `updates-popover.sh`, `calendar-card.sh`, `sound-popover.sh`, `media-popover.sh`, `weather-popover.sh`, `wallpaper-carousel.sh` and its `carousel-*.sh` helpers), `screenshot.sh`, `colorpicker.sh`, media control, night light (`nightlight.sh`) and the AI sidebar launcher (`launch-chatbox.sh`, Super+A)
  - Media: `medialib.sh` picks the player the media module follows and `mediactl.sh` controls (its header has the rule); `mediaexec.sh` renders it; `media-popover.sh` opens the media card on it ([media-card.md](media-card.md)).
- `waybar/` — Bar management (`waybar.sh`, `waybartoggle.sh`), the Bar page renderers (`bar-modes.sh`, `clock-format.sh`), the `network.sh`, `updates.sh` and `agenda-bar.sh` (next event) modules (the GPU module's `gpu.sh` sits beside the bar config in `waybar/scripts/`), `build-workspaces.sh`, plus `battery.sh`: the battery module for the whole machine. System batteries come from sysfs and always show, the alert class taking the minimum across discharging ones; peripherals come from `devices/devices.sh` and show only when it marks them low. Its header has the rules and the `BATTERY_SYSFS` test seam.
- `devices/` — `devices.sh`, the one reader of wireless peripheral batteries and connection state (USB headsets through the optional `headsetcontrol`); Waybar's battery module, the low-battery toast (`battery-alert.sh`) and the panel's Devices page all consume its JSON
- `sound/` — `sound.sh`, the only thing that moves a stream or reads the popover's pins (see Sound popover)
- `weather/` — `forecast.sh`, the only thing that asks Open-Meteo for the weather card's forecast, and the keeper of its saved copy (see Weather card)
- `calendar/` — `sync.sh`, the only iCloud path, and `cal.sh`, the only khal reader and writer (see Calendar); `setup.sh` wires the iCloud account and sync timer; `ics-edit.py` and `declined.py` are the Python helpers
- `capture/` — `record.sh`, the only driver of gpu-screen-recorder, `read-text.sh`, the only QR and text decoder (`screenshot.sh --text`), and `toast.sh`, the shared toasts (see Capture bar); `fakes/` are test stubs
- `updates/` — the update card's planner and runner (`updates-plan.sh`, `updates-run.sh`), `terminal.sh` for the terminal paths, and the Node modules `fold.mjs` and `tooltip.mjs` (see Update card)
- `settings/` — the panel's request runner (`panel-request.sh`), default file manager, file chooser and terminal wiring (`file-manager.sh`, `file-chooser.sh`, `terminal.sh`), and `update.sh`, the terminal update (AUR helper from `options/aurhelper`, then Flatpak)
- `desktop-clock/` — `desktop-clock.sh`, the only owner of the eww desktop clock (see Desktop clock)
- `theming/` — matugen generator (`generate-palette.sh`), JSON converter (`matugen-to-wal.sh`), readability scorer (`score-palettes.py`), fan-out driver (`apply-wal.sh`), shared palette loader (`palette.sh`) and `accent-run.sh`, which gives cmatrix and tty-clock the accent on their own terminal
- `fonts/` — `apply-font.sh`, which writes `options/font` and `options/font-gtk` into every config that names a font and renders the font includes into `~/.local/state`, including Strata's fontconfig rule; it edits only untracked or rendered files
- `state/` — the machine-state overlay: the engine (`overlay.mjs`), its CLI (`overlay-cli.mjs`), `overlay.sh` (`sync` and `check`, under a lock) and `derived.sh` (files computed from options); see `docs/internals/state.md`
- `spotify/` — the SpotX launch wrapper, its desktop-entry setup and the Spicetify theme selection (see Spotify)
- `ssh/` — `setup.sh`, the `~/.ssh/config` Include (see SSH agent)
- `proton/` — `setup.sh`, run once as your own user (it asks for sudo itself): takes Proton VPN's split-tunnelling daemon (`proton.VPN.service`) off boot and installs the pacman hook (`proton-vpn-on-demand.hook`) that keeps it off after package upgrades
- `keybinds/` — `keybinds-sheet.sh`, the one parser of `keybinds.lua`; `docs/` — `generate-keybindings.sh`, which renders `docs/keybindings.md` from it
- `doctor/` — the library and check modules behind `doctor.sh` (see Doctor architecture)
- `hooks/` — the git hooks (`pre-commit`, `post-merge`, with `post-checkout` a symlink to it) and `snapshot.sh`
- `lib/` — sourced helpers: `assert.sh` (test assertions, `wait_for`), `deploy.sh` (the installer's copy and backup plan), `hypr-vars.sh`, `options.sh` (the one reader of an `options/` file), `qml-test.sh` (the Quickshell suites' offscreen `qmltestrunner` in a private HOME), `qs-launch.sh` (the Quickshell launchers' checks, launch lock, IPC toggle, palette and bar-anchor export and wait for IPC) and `wallpaper.sh` (which image is the current wallpaper)

Scripts are bash, apart from the Node modules in `updates/` (`fold.mjs`, `tooltip.mjs`) and `state/` (`overlay.mjs`, `overlay-cli.mjs`), the jq programs in `calendar/` (`busy.jq`, `khal-events.jq`), one Python test stub in `capture/fakes/`, `theming/score-palettes.py`, and `calendar/ics-edit.py` and `calendar/declined.py`, which are Python because time zones and recurrence exceptions need khal's `icalendar`. They check for command existence before running and read preferences from `options/` through `lib/options.sh`. They read a tool's machine output (`--raw`, `-j`, `--json`) rather than parsing its display format, which cannot always tell data from its own framing, and they announce a success only after the command that did it has succeeded.
