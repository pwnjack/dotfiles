# Update card

Contract (behaviour, privilege model, run flow, traps: [updates.md](../updates.md)):

- `quickshell/updates/shell.qml` is the card, started by `scripts/hyprland/updates-popover.sh` (cursor-anchored). Update starts `scripts/updates/updates-run.sh` under `setsid`; `fold.mjs` folds its stream into `state.json` through the pure `model.mjs` the card also imports, so card and bar agree. [How a run flows](../updates.md#how-a-run-flows).
- The window is `quickshell/popover/BarPopover.qml`, shared with the media card, the sound popover and the weather card: it covers the output beside the bar, closes on a click outside, centres the card under the clicked x (`fallbackX` when the cursor is unknown), runs the entrance and the leave, and quits the process when a close has finished fading. Each shell passes its layer namespace; the update card does its own extra work in `onAppeared` and the sound popover in `onLeaving`. `Collect.qml` beside it is a `Process` that reports once its exit and both streams are in. Quickshell loads QML only from a config's own folder, so each card reaches `BarPopover.qml` through a tracked symlink in its directory (`quickshell/<card>/BarPopover.qml`), and the update and weather cards reach `Collect.qml` the same way (the sound popover collects its own streams); edit the file in `quickshell/popover/`.
- The root helper `/usr/local/bin/system-update` is installed from `updates/system-update-root.sh` by `updates/setup-sudo.sh`. [Setting it up](../updates.md#setting-it-up), [Privilege model](../updates.md#privilege-model).
- AUR updates stay in the terminal (`scripts/updates/terminal.sh`). [What it does](../updates.md#what-it-does).
